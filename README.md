# Invoker Hand Signs

> Cast Invoker spells with webcam-tracked hand signs — a cross-platform Python
> desktop app for Windows and Linux.

Локальное приложение: веб-камера распознаёт четыре жеста и по желанию
нажимает `Q`, `W`, `E`, `R` в активном окне игры. По умолчанию оно **не
посылает клавиши**, поэтому сначала можно спокойно настроить камеру.

Есть два способа запуска:

* `python app.py` — рекомендуемое небольшое приложение с интерфейсом Material 3:
  выбор камеры, предпросмотр, редактирование биндов и безопасный переключатель
  отправки клавиш.
* `python main.py` — упрощённый режим с окном OpenCV.

## Возможности

* Четыре понятные печати: раскрытая ладонь, кулак, V-знак и две ладони.
* Предпросмотр с наложением скелета рук и текущей последовательностью сфер.
* Material 3 приложение для выбора камеры и изменения биндов без правки кода.
* Защита от дублей: печать должна быть удержана, а перед следующей требуется
  короткое нейтральное положение.
* Windows и Linux/X11 из одного исходного кода.

## Печати

| Жест | Результат |
| --- | --- |
| Одна раскрытая ладонь | `Q` — Quas |
| Один кулак | `W` — Wex |
| V-знак (указательный и средний палец) | `E` — Exort |
| Две раскрытые ладони | `R` — Invoke |

Каждый жест держится 0,35 секунды. Между печатями уберите руки из кадра или
опустите их на 0,18 секунды: это защита от случайных повторных нажатий.

## Установка

Нужен Python 3.10–3.13. Код один и тот же для Windows и Linux.

### Windows

Откройте PowerShell в папке проекта и выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

Если команда `py -3.12` не найдена, установите Python 3.12 с python.org и
повторите команды. Windows обычно не ограничивает `pynput`; если Dota 2 всё же
игнорирует нажатия, не запускайте программу от администратора, когда сама игра
запущена обычно — оба процесса должны быть с одинаковыми правами.

### Linux

```bash

source .venv/bin/activate
```

Python 3.12 и создайте окружение командой `python3.12 -m venv .venv`.

## Первый запуск — безопасная калибровка

```bash
source .venv/bin/activate
python main.py
```

Для запуска приложения с Material 3 вместо последней команды используйте:

```bash
python app.py
```

В нём выберите камеру, нажмите «Запустить предпросмотр», назначьте клавиши в
блоке «Бинды Invoker», а затем только при необходимости включите переключатель
«Отправлять клавиши в активное окно».

Откроется камера. В верхней части показывается распознанная печать и собранная
последовательность. Никакие клавиши в Dota 2 не отправляются.

* `Esc` — закрыть программу.
* `K` — включить или отключить отправку клавиш.
* `--camera 1` — выбрать другую веб-камеру.

## Игра

После калибровки можно запустить режим клавиш:

```bash
python main.py --send-keys
```

Нажмите `K`, когда всё готово, затем сделайте активным окно Dota 2. Камера
продолжит обрабатываться в фоне. Убедитесь, что горячие клавиши героя —
`Q/W/E/R`, либо измените их в `config.example.json` и передайте файл так:

```bash
cp config.example.json config.json
python main.py --config config.json --send-keys
```

На Windows и в Linux/X11 `pynput` посылает нажатия в активное окно. В Wayland
синтетические нажатия клавиш могут быть заблокированы системой — войдите в
сеанс **X11/Xorg**, если это произошло. Некоторые игры также могут намеренно
игнорировать синтетический ввод; сначала проверьте это в тренировочном лобби.
Тестируйте такое управление в лобби или режиме тренировки и сверяйтесь с
актуальными правилами игры.

## Первые комбо

* Cold Snap: ладонь → нейтрально → ладонь → нейтрально → ладонь → две ладони.
* Tornado: ладонь → нейтрально → кулак → нейтрально → кулак → две ладони.
* Sun Strike: V → нейтрально → V → нейтрально → V → две ладони.

Последовательность печатей просто повторяет обычные `Q/W/E/R` Invoker.
